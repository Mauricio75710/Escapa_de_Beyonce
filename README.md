# Escapa_de_Beyonce

## Mauricio Castillo Oloarte

Sigue las instrucciones del video anexo para elaborar un sencillo juego de navegador que te permita familiarizarte con las estructuras básicas de JavaScript (objetos, variables, arreglos), así como el manejo de eventos en el navegador. (Si no puedes acceder al video, se anexa para su descarga).  

Una vez que ya tengas el juego listo, agrega un panel de configuración en dónde puedas modificar al menos 3 diferentes aspectos del juego (velocidad del jugador, velocidad del enemigo, fondo, música, etc.)  

Deberás subir tu proyecto a un repositorio público de GitHub y, adicionalmente, publicarlo en algún servidor para ser visualizado en línea (por ejemplo, GitHub Pages)  
 
Formato de entrega: Repositorio de GitHub  
Fecha límite de entrega: Viernes, 6 de noviembre, durante la hora de clase.
